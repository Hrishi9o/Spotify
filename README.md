# 🎵 Spotify Clone | Sigma Web Development 🚀

A high-performance, fully responsive music streaming web application built from scratch using a pure **Vanilla Web Stack**. This project was developed as a major milestone in the **Sigma Web Development Course**, focusing on DOM manipulation, asynchronous JavaScript, and advanced CSS layouts.

🔗 **Live Demo:** [https://hrishi9o.github.io/Spotify/](https://hrishi9o.github.io/Spotify/)

---

## ✨ Key Features

*   **🎧 Seamless Audio Playback**: High-quality streaming with custom play/pause and track skipping logic.
*   **⏩ Interactive Seekbar**: Real-time progress updates with a "click-to-skip" feature that calculates exact timestamps using `getBoundingClientRect()`.
*   **📱 Modern Responsive UI**: A sleek, dark-themed interface featuring a functional sidebar and SVG iconography.
*   **🔊 Intelligent Volume Control**: A precision volume slider that dynamically toggles between "Mute" and "Active" icons based on levels.
*   **🔄 Auto-Next Integration**: Smart event listeners that automatically trigger the next track when the current one finishes.
*   **📂 Library Management**: Dynamic song listing and selection through the "hrishisongs" directory structure.

---

## 🛠️ Tech Stack & Skills

*   **HTML5**: Semantic markup for a robust and accessible structure.
*   **CSS3**: Custom layouts, transitions, and utility-first styling for a premium look.
*   **JavaScript (ES6+)**: Pure "Vanilla" logic using `async/await`, Event Listeners, and the Web Audio API.
*   **Git/GitHub**: Advanced version control, including multi-object pushes and delta compression.
